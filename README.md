# Talknivo website

Static website starter. **Legal and contact pages are drafts and must be finalized before public Play Store submission.**

## Deploy
1. `firebase login`
2. `firebase projects:list`
3. From this directory: `firebase use --add` (select the existing Talknivo Firebase project)
4. `firebase deploy --only hosting`

Review the Firebase project carefully before deploying. Firebase Hosting will show the actual URL. Add verified support email, legal identity, SDK data handling, deletion process and subscription terms before public launch.
